# Tuan3 - Bài tập CSS cơ bản

Bài thực hành môn Phát triển ứng dụng Web/TMĐT.

## Cấu trúc

- `VeNha/`: mã nguồn và tài nguyên bài tập.
- `VeNha/index.html`: trang giới thiệu cá nhân và liên kết đến các bài (sẽ bổ sung).
- `VeNha/BaiTap1.html`, `VeNha/BaiTap2.html`, ...: các bài tập theo đề.

Đưa từng bài và các tài nguyên liên quan lên Git bằng các commit riêng. Không nén mã nguồn khi đưa lên GitHub.
